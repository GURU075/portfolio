# Gururaj Yadav — Portfolio

My personal software engineering portfolio, built to showcase my full-stack
projects, technical skills, and approach to building reliable products.

## Technologies used

- Next.js
- React
- TypeScript
- Tailwind CSS
- HTML and CSS
- Git and GitHub
- GitHub Actions
- GitHub Pages

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run test:static
```
